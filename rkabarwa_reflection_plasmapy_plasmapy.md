# Reflection: plasmapy_plasmapy

Activity pattern: rising. Longest gap: 2016-01 to 2016-09 (9 months). Gaps of 3+ months: 2. Current status: Active.

PlasmaPy is the clearest rising trajectory in the set, growing from 925 commits in 2017 to a peak of 5,367 in 2022 and staying in the thousands since. It has only two gaps of three or more months, and the longest (2016-01 to 2016-09, 9 months) sits at the very beginning.

The gap was easy to interpret because the repository held no code at the time. The ten commits before it, all on 2015-12-01, rename README and license files and add a code of conduct; no issues or pull requests existed. The project was being organised, not developed. Recovery began in October 2016 with a citation to the APS DPP 2016 presentation and the first real code in February 2017 from a new contributor. The founder stayed, hundreds of contributors joined, and the most recent commits are dominated by dependabot and lock-file automation, which is typical of a large, mature project with heavy CI.
