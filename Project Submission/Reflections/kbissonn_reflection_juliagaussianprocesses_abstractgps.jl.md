# juliagaussianprocesses_abstractgps.jl Reflection
## Inactivity Patterns
- This project has been becoming more and more inactive as months with commits are seperated by more time spent being inactive. This project also jumps pretty substantially from month to month as a lot of commits will be made one month then very few the month following, leading to a lot of spikes in the graph.

## Difficulty Interpreting Longest Gap
- There really wasnt a long gap that happend at once, but there have been periods of signifigantly lower commits. The trouble came from why this pattern showed itself rather than finding the gaps themselves.

## Likely Reasons For Inactivity/Recovery
- The most likely reason for the inactivity is the high turnover rate of the project as it is appears that every gap in commits is a result from a new developer working on the project. 

## Activity Patterns
- Overall, the activity is still pretty constant when commits are being made; however, the gaps inbetween months of commits have been growing, so I would describe the project as declining.
