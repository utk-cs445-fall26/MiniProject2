# darrencroton_sage
## Inactivity Patterns
- This project jumps all over the place with a lot of months being active while other months have a substantial number of commits. The only pattern that is really discernable with this project is a long period of inactivity (about 4 years) of very little commits before a staggering spike in new activity. 

## Difficulty Interpreting Longest Gap
- The longest gap was very easy to find; however, the smaller gaps are much harder to interperate as there are so many of them.

## Likely Reasons For Inactivity/Recovery
- I am unsure about the reason for the long inactivity, but my best guess would be that the main developer became busy with other projects and no longer had time to develop for it. Then the sudden spike was the developer's way of getting the project in a state where they could pass it off as the later commits are from a new developer.

## Activity Patterns
- The activity pattern of this project was highly irregular with no discernable pattern outside of the long period of inactivity.
