# Reflection: snakemake-workflows_rna-seq-kallisto-sleuth

Activity pattern: steady. Longest gap: 2020-05 to 2020-07 (3 months). Gaps of 3+ months: 1. Current status: Active.

This Snakemake workflow is the steadiest project in the set, with 115 to 382 commits every year since 2019 and only one gap of three or more months: 2020-05 to 2020-07.

The gap was easy to interpret as a pause after a sprint. April 2020 contains two feature pull requests (IHW FDR control, differential splicing) and a dense run of CI and Docker fixes by the lead developer. Once those landed the two core developers stopped for three months. A user issue in August 2020 about the template copy failing prompted the removal of an oversized test report and a biomart caching fix, and regular maintenance resumed. The same two maintainers are still active in late 2025, now with release automation producing version tags (v4.0.0 in October 2025). This is a healthy, continuously maintained pipeline.
