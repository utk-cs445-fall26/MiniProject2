# JuliaIntervals/IntervalArithmetic.jl

The four-month gap in the project's early history is easy to locate, but there are no nearby issue or pull-request records that explain it. Work immediately before the gap included [PR #7](https://github.com/JuliaIntervals/IntervalArithmetic.jl/commit/54a050b5e8cd3305ef6e21563d22e5713d862cc5) for parameterized intervals and root-finding; the first commit afterward updated the changelog for version 0.0.3, making an early release-cycle pause plausible but unproven. A README update followed in May 2015, and the project later accumulated substantial long-term activity. Different contributors appear at the boundary—Luis Benet merged the pre-gap PR and David P. Sanders wrote the changelog update—though the public record does not establish a deliberate handoff.
