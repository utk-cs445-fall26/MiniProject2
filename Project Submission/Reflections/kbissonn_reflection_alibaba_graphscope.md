# alibaba_graphscope Reflection
## Inactivity Patterns
- This project started off with a lot of inactivity before actually picking up. Then it had a good amount of activity for about 4 years before starting to die back down where it is pretty inactive. 

## Difficulty Interpreting Longest Gap
- The longest gap for this project was pretty easy as there are only 2 gaps in the project, one at the beginning and the other at the end.

## Likely Reasons For Inactivity/Recovery
- This inactivity is likely due to two reasons. One, the company this project was for just getting started with the repository beign created right after the initial pitch and the company having to find people to dedicate to it. Two, the porject came to an end where the program was fully developed and the internal project was marked as complete.

## Activity Patterns
- The project started slow before peaking at the middle of the projects production lifecycle. Since this peak, it has been declining to the point where it is now being inactive apart from the occation fix.
